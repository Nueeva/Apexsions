# 🌟 Dokumentasi PlaceholderAPI — ApexsionsJobs

> **Plugin:** ApexsionsJobs  
> **Identifier PAPI:** `%apexsionsjobs_*%`  
> **Versi:** 1.0.0  

---

## Daftar Placeholder Resmi

| Placeholder | Tipe Output | Deskripsi & Contoh Nilai |
| :--- | :--- | :--- |
| `%apexsionsjobs_active%` | Teks | Nama profesi aktif pemain saat ini (Contoh: `Miner`, `Farmer`, `None`). |
| `%apexsionsjobs_level%` | Angka (Integer) | Level profesi aktif pemain saat ini (Contoh: `15`). |
| `%apexsionsjobs_exp%` | Angka (Decimal) | Jumlah EXP profesi aktif saat ini (Contoh: `450`). |
| `%apexsionsjobs_req_exp%` | Angka (Decimal) | EXP yang dibutuhkan untuk naik ke level berikutnya (Contoh: `1875`). |
| `%apexsionsjobs_daily_earned%` | Angka (Format) | Total gaji yang telah diperoleh hari ini (Contoh: `85,000`). |
| `%apexsionsjobs_level_<job>%` | Angka (Integer) | Level pemain pada pekerjaan tertentu (Contoh: `%apexsionsjobs_level_miner%` -> `24`). |
