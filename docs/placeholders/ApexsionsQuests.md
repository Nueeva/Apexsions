# 🌟 Dokumentasi PlaceholderAPI — ApexsionsQuests

> **Plugin:** ApexsionsQuests  
> **Identifier PAPI:** `%apexsionsquests_*%`  
> **Versi:** 1.0.0  

---

## Daftar Placeholder Resmi

| Placeholder | Tipe Output | Deskripsi & Contoh Nilai |
| :--- | :--- | :--- |
| `%apexsionsquests_streak%` | Angka (Integer) | Jumlah hari login streak berturut-turut pemain saat ini (Contoh: `12`). |
| `%apexsionsquests_highest_streak%` | Angka (Integer) | Rekor streak login tertinggi yang pernah dicapai pemain (Contoh: `45`). |
| `%apexsionsquests_freeze_tokens%` | Angka (Integer) | Jumlah Streak Freeze Token yang dimiliki pemain (Contoh: `2`). |
| `%apexsionsquests_today_claimed%` | Teks | Status klaim hari ini: `Ya` atau `Tidak`. |
| `%apexsionsquests_daily_completed%` | Angka (Integer) | Jumlah quest harian yang telah diselesaikan hari ini (Contoh: `3`). |
| `%apexsionsquests_daily_total%` | Angka (Integer) | Total kuota quest harian yang diberikan (Contoh: `4`). |
| `%apexsionsquests_passive_multiplier%` | Persentase | Bonus pasif pendapatan dari streak aktif (Contoh: `10%`). |
